AgenticSionna: Intent-Driven Wireless Network Experimentation with Self-Evolving Agents

A self-evolving language-agent system for natural-language 3D radio environment construction and executable Sionna wireless simulation.

Abstract

Wireless network simulation and optimization are difficult because they require solving a complex cross-layer configuration problem while interacting with complex 3D radio environments. For decades, engineers have relied on channel models, channel simulators, and extensive standards to guide this process, but using them correctly still requires substantial domain expertise and engineering effort. Recent language-model agents can automate parts of wireless reasoning and code generation, yet they are not trained for the cross-layer setting in which an agent must construct a 3D radio environment, bind it to radio and network assumptions, and run simulations inside it.

We present AgenticSionna, a self-evolving language-agent system for intent-driven wireless network simulation. AgenticSionna converts a natural-language request into an executable radio environment that combines a 3D radio environment with a cross-layer wireless-system configuration and optimization. The system uses a multi-agent architecture with specialized scene-building, simulation, reflection, planning, and skill-learning agents. It learns from previous tutorials, worked examples, prior simulation results, and its own failed trajectories, then updates a procedural skill and knowledge base through verifier-driven optimization.

We evaluate AgenticSionna on benchmark suites covering 3D radio environment generation, wireless simulation, and token efficiency across multiple indoor and outdoor scenarios. On 3D radio environment generation, AgenticSionna reaches 72.5% held-out pass rate, compared with 0.0% for both Naive LLM and Self-Written Skill. On wireless simulation, AgenticSionna achieves an average 82.5% pass rate, compared with 0.0% for Naive LLM and 1.25% for Self-Written Skill, while reducing generated tokens by 32.0% on average.
